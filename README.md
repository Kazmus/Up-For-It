# Up For It

CONTEXTE
Construis une landing page d'une seule page pour Up For It (SRL belge). Up For It accompagne l'horeca, les commerces et les freelances en Belgique, avec une approche terrain, sans grandes théories. Signature : "Construisons votre succès". Deux portes d'entrée : UFI Studio (conseil et production pour les établissements déjà ouverts) et UFI Academy (formation pour structurer, lancer ou relancer un projet).

CIBLE
- Studio : gérants d'établissements ouverts qui luttent avec la rentabilité, la trésorerie, une équipe sous tension ou une visibilité en ligne faible.
- Academy : porteurs de projet en reconversion, en sortie de chômage ou qui lancent leur premier établissement.
Ils savent qu'ils ont besoin d'aide mais ne savent pas par où commencer.

OBJECTIF / ACTION CLÉ
Une seule action : demander un conseil d'orientation. CTA principal : "Me faire conseiller". CTA secondaires dans chaque carte : "Découvrir le Studio" et "Découvrir l'Academy".

STRUCTURE (dans cet ordre)
1. Header : logo texte "UP FOR IT" + menu (Studio, Academy, À propos, Références, Contact) + bouton "Me faire conseiller".
2. Hero : titre "Des projets horeca qui tiennent la route." Sous-titre : "Horeca, commerces, freelances : on travaille avec votre réalité, pas avec des grandes théories." Bouton "Me faire conseiller".
3. Deux portes : 2 cartes côte à côte (empilées sur mobile).
   - Studio, "Vous êtes plutôt Studio si" : établissement déjà ouvert ; rentabilité ou trésorerie difficile ; équipe mal structurée ; visibilité en ligne qui ne suit pas.
   - Academy, "Vous êtes plutôt Academy si" : projet en cours de structuration ; reconversion ou sortie du chômage ; premier établissement ; besoin de clarté sur le concept, les chiffres et les étapes.
4. Orientation : bloc court "Vous hésitez entre les deux ? On vous oriente, sans forcing commercial." + bouton.
5. Témoignages : 3 cartes (citation courte, 3 résultats en puces, prénom + type d'établissement) : Alex, bar à vin et tapas ; Sarah, concept food multi-sites ; Jean, projet de café après une période de chômage.
6. Primes et aides : certains accompagnements peuvent être partiellement cofinancés par des aides publiques ; Up For It aide à vérifier l'éligibilité et à préparer le dossier. Mention obligatoire : "L'obtention d'une prime dépend des organismes publics et n'est jamais garantie."
7. CTA final : "Construisons votre succès" + formulaire (nom, e-mail, téléphone, choix Studio / Academy / Je ne sais pas, message) + bouton "Me faire conseiller".
8. Footer : téléphone +32 (0)479 09 19 09, Instagram, Facebook, LinkedIn, lien "Espace Learning", mentions légales, confidentialité, cookies.

DIRECTION VISUELLE
Terrain, direct et chaleureux, sans jargon. Beaucoup d'espace blanc, cartes aux coins arrondis, ombres légères, photos d'ambiance horeca. Couleurs : orange Up For It (#F28C28) pour les CTA, bleu-turquoise (#3AA0C0) pour les accents, texte gris très foncé (#1F2933). Police : Inter.

CONTRAINTES
- Mobile-first : le hero et le CTA doivent être lisibles sans scroll sur téléphone.
- Texte en français, aucun lorem ipsum.
- Un seul H1, titres H2 par section, textes alternatifs sur les images.
- Performance : pas de vidéo lourde dans le hero.
- Pas de backend pour l'instant : le formulaire affiche un message de confirmation.
